01 / SET UP THE CONTEXT

Open a real model.

Jev grounds its decisions in the project you have open. Start with the bundled IFC model or add your own semantic IFC file.

  1. 1
    Launch the Windows desktop app and sign in to your local workspace.
  2. 2
    In Workspace account, add your Jev API key. Add a DeepSeek key for parameter extraction and explanations of unsupported requests.
  3. 3
    Use Append model to import an IFC, or begin with the included Duplex IFC. Check the model tree before asking a model-specific question.

READY WHEN The model appears in the tree and the Jev prompt is available.

02 / TELL JEV WHAT YOU NEED

Ask in plain English.

Use the Jev prompt at the bottom of the workspace. A specific request gives Jev a clear action and target.

  1. 1
    Try “List all door entities.” to query IFC semantics without manually navigating the tree.
  2. 2
    For coordination, ask for one action at a time: run an existing clash test, show a result, or change its review status.
  3. 3
    Press Enter or the run button. Jev selects a supported tool and validates model-specific targets before execution.

TIP DeepSeek can extract free-form parameters and explain unsupported requests.

03 / INSPECT THE OUTCOME

See what happened.

Jev shows its completed decision path and the resulting BIM output. Keep the human in the loop by inspecting the result in the model.

  1. 1
    Read the action and result in the Jev panel. Select a returned item to show it in the viewer when available.
  2. 2
    Check the model, properties, clash result, or issue before continuing. Ask a follow-up as a separate action.
  3. 3
    Open Activity Log to inspect the recorded interaction and its outcome. Unsupported requests are shown as unavailable instead of silently changing the project.

04 / TURN USE INTO LEARNING DATA

Build the feedback loop.

Real usage can reveal which paths worked and where the assistant needs improvement. SophonBIM turns local activity into material people can review.

  1. 1
    Open Episode Labeling. Runtime actions are grouped into task Episodes while the original log stays intact.
  2. 2
    Label intent, outcome evidence, useful steps, and preferred paths; submit the annotation for independent review.
  3. 3
    In Dataset versions, build a draft from eligible reviewed Episodes, inspect quality, then freeze and export a versioned dataset.

LEARNING LOOP The exported dataset can support future evaluation and model improvement; the app does not retrain itself automatically.
